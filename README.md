# PPT-sidle-
Educational PPT Digitization and Structured Content Extraction

## Dataset Structure
这是 Dual Prompt-Gate: A Training-Free Dual-Expert Framework for Educational PPT Digitization and Structured Content Extraction 中使用的自建数据集。

- `final`：校准后的 OCR 结构化内容
- `frame`：图像文件
- English: In this self-built dataset, `final` stores calibrated OCR structured content, and `frame` stores image files.
