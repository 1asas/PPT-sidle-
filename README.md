# PPT-sidle-
Educational PPT Digitization and Structured Content Extraction
Dual Prompt-Gate: A Training-Free Dual-Expert Framework for Educational PPT Digitization and Structured Content Extraction 中自建数据集，final 为校准后的 OCR 结构化内容，frame 为图像文件。
In the self-built dataset of "Dual Prompt-Gate: A Training-Free Dual-Expert Framework for Educational PPT Digitization and Structured Content Extraction", `final` stores calibrated OCR structured content, and `frame` stores image files.
